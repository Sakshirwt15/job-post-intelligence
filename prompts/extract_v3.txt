Extract structured job details from messy job posts (English/Hinglish). Return ONE JSON object only.

Keys: company (string), role (string), employment_type ("internship"|"full-time"|"contract"|"unknown"),
batch ([int]), stipend_min (int|null, INR/month), stipend_max (int|null, INR/month), location (city string|null),
is_remote (bool), skills ([string]), apply_link (string|null), apply_email (string|null).

Rules: pay as plain monthly INR integers ("25k" -> 25000; LPA / 12); null if unknown; never invent data;
remote-only -> location null + is_remote true; copy links exactly.

### Example 1
POST:
🚀 HIRING ALERT 🚀
Zephyr Labs is looking for Data Analyst Intern (Pune, onsite)
Stipend: 15k-20k/month | 2025 & 2026 passouts
Skills: SQL, Excel, Power BI
Apply 👉 https://forms.gle/abc123XY

{"company":"Zephyr Labs","role":"Data Analyst Intern","employment_type":"internship","batch":[2025,2026],"stipend_min":15000,"stipend_max":20000,"location":"Pune","is_remote":false,"skills":["SQL","Excel","Power BI"],"apply_link":"https://forms.gle/abc123XY","apply_email":null}
